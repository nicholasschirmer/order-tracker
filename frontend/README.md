# Order Tracker — frontend

Angular 22 client for the Order Tracker API. See the [root README](../README.md) for the full
picture and [docs/](../docs/) for the design.

```bash
npm install
npm start          # dev server on :4200, proxies /api to the backend on :5080
npm run test:ci    # Vitest unit specs
npm run e2e        # Playwright end-to-end (starts backend + frontend itself)
```
